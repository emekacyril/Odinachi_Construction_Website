ODINACHI CONSTRUCTION COMPANY LIMITED — EDITABLE WEBSITE

HOW TO EDIT
1. Extract this ZIP folder.
2. Open the extracted folder in Sublime Text (File > Open Folder).
3. Open index.html to edit the page structure/content.
4. Edit css/style.css for colours, layout, fonts and appearance.
5. Edit js/config.js for company details, email, phone, WhatsApp, text and image mapping.
6. Edit js/main.js for interactive behaviour (navigation, project filters, gallery, etc.).
7. Keep the images folder and its contents in place; the website uses these paths.

EMAIL
The contact email has been updated to Odinachiconstructioncompany@gmail.com in js/config.js.

PREVIEW
Open index.html in a browser. For best results, use a local development server (for example, VS Code Live Server) because some browser features may restrict local files.

FOLDER STRUCTURE
index.html       Page structure
css/style.css    All website styling
js/config.js     Editable company content and image paths
js/main.js       JavaScript functionality
images/          Website photographs and video
